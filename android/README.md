# ThinkBuddy – Android App (Kotlin / Jetpack Compose)

This directory hosts the Android MVP application built with:
- **UI:** Jetpack Compose, Material 3, WindowSizeClass (phone + tablet adaptive layouts).
- **Architecture:** MVVM, Clean Architecture, Hilt DI.
- **Networking:** Retrofit + OkHttp (HTTP/2), SSE client for token streaming.
- **Local Storage:** Room for offline today's plan caching, Jetpack DataStore for preferences.
- **Security:** Hardware-backed Keystore, Screen Pinning, SafetyNet/Play Integrity verification for assessed quizzes.
